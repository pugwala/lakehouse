# docs

Snapshots of the lab's working documents, kept here for safe keeping. Each one is a Markdown export of a
living Claude Doc. **The Claude Doc is the current copy**; these files are refreshed whenever a doc changes,
so they can trail it by a step. Network addresses and logins are redacted (`<tailnet-host>`, `<tailnet-ip>`,
`<vm-lan-ip>`, `<proxmox-host-ip>`, `<owner-user>`).
